# Weather Dashboard

## About the Project

A responsive Weather Dashboard built using HTML, CSS, and JavaScript as part of the IYF Season 12 Week 6 assignment. The application uses the OpenWeatherMap API to retrieve and display real-time weather information for different cities.

## Features

- Search for weather information by city.
- Display real-time weather conditions.
- Show temperature in Celsius.
- Display feels-like temperature, humidity, wind speed and atmospheric pressure.
- Loading and error messages.
- Save the five most recent city searches using localStorage.
- Search again by clicking a previous search.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Promises
- Async/Await
- OpenWeatherMap API
- localStorage
- Git and GitHub

## Installation and Setup

1. Clone the repository.
2. Open the project folder in VS Code.
3. Create your local `config.js` file using `config.example.js` as a guide.
4. Add your OpenWeatherMap API key to `config.js`.
5. Open `index.html` using Live Server.

**Note:** The `config.js` file is excluded from Git to protect the API key.
